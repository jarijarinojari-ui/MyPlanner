# 게스트와 집중 기록

`/guest`는 로그인 없이 사용할 수 있다. 홈과 로그인 화면에 진입 링크가 있다. 게스트의 일간·주간·월간·집중 기록은 `planner.guest.v1.*` localStorage 키에만 저장된다. 로그인한 계정의 서버 기록과 합치지 않는다. 브라우저 데이터 삭제 시 사라지며, 저장 불가 시 오류를 표시한다.

일간 하단 타이머에서 기록 이름(40자), 포모도로 또는 스톱워치를 선택한다. 포모도로는 기본 25분이며 1~180분으로 변경할 수 있다. 집중 완료 시 기록을 종료하고 5분 휴식 타이머를 표시한다. 다음 집중은 시작 버튼으로 시작한다. 휴식은 집중 시간에 포함하지 않는다. 스톱워치는 종료할 때까지 측정한다. 모든 기록은 선택 중인 과거 날짜가 아니라 실제 시작 시각에 귀속된다.

종료 버튼, 모달 X/Escape, 페이지 이탈 시 종료 저장한다. 계정 모드는 서버 시작 시각과 15초 간격 heartbeat를 사용한다. 브라우저 강제 종료·네트워크 단절로 종료 요청이 도착하지 않으면, 90초 넘게 heartbeat가 없는 기록을 다음 조회/시작 때 마지막 확인 시각으로 종료한다. 따라서 강제 종료의 정확한 순간까지 보장하지는 않으며 정상 heartbeat 간격에서 최대 약 15초가 빠질 수 있다. 절전이나 브라우저의 백그라운드 타이머 제한도 중단으로 처리될 수 있다. 재접속으로 멈춘 타이머를 자동 재개하지 않는다.

계정 타이머는 사용자 행 잠금으로 중복 시작을 막는다. 다른 계정의 기록은 조회·종료할 수 없다. 종료는 여러 번 요청해도 시간이 늘어나지 않는다. `focus_record`는 독립 테이블이므로 일반 주간 일정 저장으로 지워지지 않는다. 현재 ddl-auto=update 설정에서는 앱 시작 시 생성된다.

일간 목록은 해당 날짜와 겹친 구간만 합산하여 보여준다. 주간은 05:00~다음 날 03:00에 해당하는 위치에 보라색으로 겹쳐 표시하며 기존 일정 편집을 막지 않는다. 03:00~05:00 구간은 해당 날짜 상단에 시간표 밖 기록으로 표시한다.

검증: `./gradlew test --tests '*FocusServiceTest' --tests '*AuthPageTest'`, `node --test src/test/js/guest-api.test.cjs`.

커뮤니티, 공개 범위 설정, 이름별 통계·공유 기능은 이번 범위에 포함하지 않았다. 집중 기록은 실제 집중 여부를 증명하는 인증 수단은 아니다.
